# 简单确定性脚本基线

该基线代表既有清单编制中常见的固定格式批处理脚本。它与其他机器方法一样从原始环境统计基表开始，输入为六个工作簿：基102设备/燃料表、四个基101企业主表分片和一个基101治理设施表。其能力边界为：

- 按预先设定的工作表名、表头和字段映射读取六个固定格式原始基表；
- 从 5,922 个候选源中按固定行业代码与设备类型映射直接判定工业锅炉、火电热力或范围外；
- 使用独立冻结的燃料名称、燃烧技术、排放因子和燃煤参数查表；
- 按企业键与排放口代码直接关联治理设施，依据固定关键词表匹配脱硫、脱硝和除尘工艺；同类多设施取最大填报效率；
- 完成基本单位换算、物料衡算和排放量公式；
- 将结果按预设列顺序生成工作簿。其中 4412 始终进入“电力生产”子部门，不使用“电力供应”因子。

它不构造“污染物排放核算项”，不加载本文声明式可执行规则包，不执行逐项核算准入控制，不区分复杂阻断原因，不生成字段级血缘、规则编号和完整中间轨迹，也不具备 Agent 的阶段组织与异常汇总能力。运行时仅保留评价程序独立复算所需的最小数值记录，该记录不构成完整过程记录。

`lookups/` 是基线自身的固定查表快照；正式运行不读取 `rules/frozen/` 或 Full 的 Plugin。

每次运行输出：

- `source_decisions.csv`：所有当前候选源的固定分类结果；
- `source_pollutant_totals.csv`：目标源类的源—污染物总值及最小复算数值；
- `generic_inventory_items.csv`：仅含清单总值的通用输出界面，不伪造单位活动水平或单位因子；
- `exceptions.csv`：固定输入或查表无法直接解析的简单异常；
- `简单确定性脚本目标清单.xlsx`：预设模板化结果表。

基线可保留评价器独立数值复算所需的最小活动水平—因子—效率数组，但不保留字段来源、规则编号、中间公式或阶段调用轨迹，因此不构成 Full 的完整计算过程记录。
