# 固定燃烧源候选规则包规范

## 输入边界

- 唯一标准输入：`1 城市大气污染源排放清单编制技术指南 T_CSES 144-2024.pdf`。
- 冻结范围：通用核算方法与公式、第7章、第8.3节、第15章，以及附录A、C、D、E.1和E.7。
- 禁止读取既有规则工作簿、计算答案、原计算公式、实验输出或参照标签。

## manifest.yaml

必须包含：

```yaml
package_id: tcses-144-2024-fixed-combustion
version: 0.1.0-candidate
status: awaiting_professional_review
standard:
  name: T/CSES 144—2024
  path: <原PDF绝对路径>
  sha256: <PDF SHA-256>
scope:
  chapters: []
  appendices: []
files:
  - path: rules/scope.yaml
    sha256: <文件SHA-256>
```

`files` 列出除 `manifest.yaml` 自身外的全部候选包文件。

## YAML规则格式

每个规则文件为：

```yaml
rules:
  - rule_id: 唯一且稳定的英文编号
    rule_type: scope|method|formula|control|quality_control
    source:
      document: T/CSES 144—2024
      section: 条款、公式或附录表号
      physical_pdf_pages: [1]
    scope: {}
    conditions: {}
    action:
      type: select_scope|select_method|assign_formula|assign_control|check_quality
    on_missing: withhold|not_applicable|report_issue
```

不得把标准没有给出的数值补成0。资料性附录参数须保留表号和单位。规则条件不能只写成自然语言段落；要用键值、列表或明确运算符表达。

## 参数CSV字段

### power_heat_emission_factors.csv / industrial_boiler_emission_factors.csv

```text
parameter_id,sector,department,fuel,combustion_technology,pollutant,mode,value,unit,capacity_condition,source_section,physical_pdf_page
```

`mode` 允许 `constant`、`coal_sulfur_balance`、`coal_particle_balance`、`capacity_lookup`、`unavailable`。数值0与标准未给出必须严格区分。

### coal_parameters.csv

```text
parameter_id,sector,department,combustion_technology,sulfur_to_bottom_ash,ash_to_bottom_ash,pm25_fraction,pm10_fraction,bc_fraction_of_pm25,oc_fraction_of_pm25,source_section,physical_pdf_page
```

### control_efficiencies.csv

```text
parameter_id,control_technology,pollutant,efficiency_percent,particle_fraction,source_section,physical_pdf_page
```

### ammonia_slip_factors.csv

```text
parameter_id,process,activity_fuel,pollutant,value,unit,source_section,physical_pdf_page
```

## 映射CSV字段

只登记标准原词，不为源表编造别名：

```text
standard_value,category,source_section,physical_pdf_page
```

## JSONL测试格式

每行一个对象：

```json
{"test_id":"...","rule_id":"...","case_type":"normal|boundary|missing|not_applicable","input":{},"expected":{}}
```

至少覆盖：范围分类、活动水平单位、煤SO2物料衡算、煤颗粒物/BC/OC、容量分档NOx、常数因子、治理污染物对应、PM10细粗粒径计算、NH3氨逃逸、缺失参数阻断以及质量约束。

## 复核快照

`professional_review_snapshot.md` 只汇总：规则数量、参数表数量、测试数量、标准范围、关键公式、附录参数表、自动检查结果和需专业确认事项。状态必须为“待环境专业复核”。
