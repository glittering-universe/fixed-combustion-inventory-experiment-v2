# D/N/E 正式评价 v2

v2 不修改旧评价器，也不从旧 `S/A/Q/T/R/E` 分数换算新分数。它直接从封存运行、规范化输出和冻结参照包重新生成原子判定。

## 主评价

仅实验 A 进入核心综合分数：

\[
\mathrm{EICPI}_{\mathrm{core}}
=100(0.35D+0.35N+0.30E).
\]

- `D` 为专业决策有效性：源去向、终态处置、核算依据、污染物相关治理参数和异常根因的正确原子数除以可适用原子数。
- `N` 为数值完整性与正确性：结果完整、与冻结参照值一致、可独立复算三类原子。缺少必须输出只在完整性原子中失分；因值不存在而无法判定的值一致性和复算原子记 `NA`，避免重复惩罚。
- `E` 为相对运行时间效率。工业锅炉和火电热力分别用本次实验 A 的人工秒/条作为 0 锚点、简单确定性程序中位秒/条作为 1 锚点，对数归一后截断到 `[0,1]`。

不设置独立质量门槛。任一核心维度为 `NA` 时，该层综合分保持 `NA`，不用其他维度补齐。

## 治理参数的污染物相关比较

- SO₂、NOx 及其他非颗粒物：只比较实际去除效率。
- PM₁₀：只比较细颗粒和粗颗粒效率。
- PM₂.₅、BC、OC：只比较细颗粒效率。
- NH₃：作为 SCR/SNCR 氨逃逸的独立核算项比较方法与因子，不计入燃烧治理效率原子。

与当前污染物无关的字段即使填充形式不同，也不判为决策错误。

## 人工结果的可观察性

既有专家主导型结果中可直接观察的源去向、终态、异常处置和数值结果正常计分。当原工作簿没有留存字段来源、参数来源或中间复算输入时，相应核算依据、治理过程和内部复算原子记 `NA`，不记为 0。

## 宏平均与微平均

- 宏平均：工业锅炉与火电热力等权。
- 微平均：`D/N` 合并两类源的通过/可适用原子；`E` 按目标源记录数加权。

两者同时报告，不在计算后选择更有利的一种。

## 独立实验报告

- B1：B0 与 S1–S4 的方法内语义保持。
- B2：受影响项处置、根因、定向检出、未受影响项和负对照分别报告分子/分母。
- C：25%、50%、75%和100%规模的时间与资源分布。
- D：各消融版本与同源类 Full 的 `D/N` 变化；不计算消融版本综合分。

## 运行

```bash
python evaluation/aggregate_experiment_results_v2.py \
  --reference-package reference/frozen/<version>
```

默认生成：

- `run_scores_v2.csv`
- `aggregate_summary_v2.json`
- `experiment_B1_v2.json`
- `experiment_B2_v2.json`
- `experiment_C_v2.json`
- `experiment_D_v2.json`

参照包是经复核的冻结实施参照，`D/N` 表示与该参照的一致程度，不表示与独立现场测量真值的一致程度。
