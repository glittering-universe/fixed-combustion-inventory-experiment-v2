# Formal Evaluation v2.1.0

本目录记录正式实验完成后的 D/N/E 评价协议修订。原始输入、方法包、规则包、参照包、150 个封存运行、Hermes 会话、核算工作簿及运行耗时均未改变；实验数据仍由 `formal-experiment-v2.0.0` 提供。

修订针对 v2.0 中专业决策有效性 D 的类别失衡问题：异常判断只占全部决策原子的极小部分，直接池化会让大量常规核算项掩盖异常识别与处置错误。v2.1 改为：

```text
D = mean_available(D_regular, D_exception)
```

其中 `D_regular` 评价常规专业判断，`D_exception` 以异常源为单位，联合检查异常根因集合和受影响污染物的终态处置。旧原子微平均 D 仅保留为诊断值。实验 B2 另以 26 个合格受控对象计算五分类宏平均 F1，不进入 EICPI。

该修订明确标记为实验后的评价协议修订，不追溯性地声称为预注册指标。
