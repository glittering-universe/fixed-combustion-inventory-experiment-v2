# 固定燃烧源排放清单论文写作材料

用于撰写研究背景、方法、实验结果和讨论。研究数据来自2022年环境统计基表，核算依据为T/CSES 144—2024。

## 材料目录

| 目录 | 写作用途 |
|---|---|
| [研究背景](论文写作材料/01_研究背景) | 研究对象、问题定位、文献线索 |
| [方法与实验设计](论文写作材料/02_方法与实验设计) | 方法组成、对比方法、A—D实验安排、评价指标 |
| [实验结果](论文写作材料/03_实验结果) | 主实验、鲁棒性、规模、消融及150次逐次结果 |
| [核算依据](论文写作材料/04_核算依据) | 技术指南、参数、规则、参照汇总和专业问题条目 |
| [人工对照](论文写作材料/05_人工对照) | 两份人工原表、表头读取与任务条件说明 |

## 常用入口

- [实验A方法比较](论文写作材料/03_实验结果/A_方法比较.csv)
- [实验结果表说明](论文写作材料/03_实验结果/结果表说明.md)
- [评价指标](论文写作材料/02_方法与实验设计/评价指标.md)
- [参照使用与专业问题](论文写作材料/04_核算依据/参照使用与专业问题.md)
- [人工对照条件](论文写作材料/05_人工对照/人工结果说明.md)

CSV文件可直接用于论文制表和绘图。各项得分沿用现有实验结果；指标口径、人工对照条件、计时依据和专业适用性说明与结果配套阅读。
