## 文件命名规范

- **评价_*.csv**：实验分组的论文评价结果，原表数据不变。
- **人工_<组别>_<源类>_<内容>.csv/json**：对应人工流程的源分类、污染物结果、异常清单、运行摘要。组别例如 `B0`、`S1`–`S4`、`B2`；源类 `IND` 为工业锅炉，`POW` 为火电热力。
- **人工_IND/POW_原始工作簿.xlsx**：实验A的历史专家流程原始工作簿，不等同于B0新补充的人工结果。
- **设计_*.csv / 校验_*.csv**：实验B2对象、参数依赖和异常注入验证材料。
- **总运行记录.csv**：每条 `run_id` 唯一；`分类实验`为A、B0、B1、B2、C、D，`实验组别`标明S1–S4、规模百分比、消融配置等；保留原有分数、运行编号和会话字段。

**统计口径：** 158是运行级索引及人工补充记录数，不是不同源对象数量。B2为300个实验对象，对应14条机器运行与2条人工结果记录。总表中 `experiment` 字段保留历史值（B0/B1原为B），新增 `分类实验` 才是统一分类；缺失评分仍为空，不以零填充。

## 整理边界

本次整理只调整Git追踪文件的目录、命名和说明，保留迁移文件的**原始Blob内容**，不重新执行实验、不重算指标。删除的是旧版平行索引和重复说明；Git历史中可回溯此前路径和文件。迁移后的唯一总表由原158条评分数据与158条会话索引按运行编号一一匹配合并。
