# 参照使用与专业问题

本目录保存实际采用的参数、映射、规则、参照汇总及问题条目。排放量单位为吨/年；B0与B2代表不同输入条件，应分别使用。

规则参照由独立实现生成。它可用于比较方法执行的一致性，专业适用性仍需结合下列已记录问题解释。

| 问题 | 已记录的影响 |
|---|---|
| 电力供应、其他气体燃料、燃气锅炉的一个VOCs参数 | 参数表记录0.02 g/m³，标准页对应0.05 g/m³；当前数据命中0次 |
| 机械＋湿法治理映射 | 16源命中；补入湿式成分的诊断复算涉及5源、21个排放结果 |
| NH₃适用性的信息选取 | 187个源涉及终态与经验处置标记的区分 |
| 行业分流与原设备治理类别的关联 | 137个源的治理候选集合不同，其中110个在原设备类别下存在候选；具体关联与修正后排放量待核定 |
| B2煤耗缺失的影响集合 | 一个对象的影响集合漏列NH₃，影响“未受影响项保持率”的解释 |
| 异常名称归一 | 同义描述与原生原因码的归类差异，需要按业务含义统一 |

“专业问题涉及源记录.csv”列出326个去重源，包括逻辑或映射涉及源与治理关联待核源。这些问题存在重叠，应按文件中的源编号区分。

“湿式成分诊断复算.csv”保存21项诊断变化，属于单项规则成分调整的影响分析。正式实验结果仍按实际运行口径呈现。

E.7气体因子的单位解释、治理信息缺失的经验处置、投运率和多工艺组合方式，也应在方法与局限性中明确。标准编号和原文页码保留于参数表，便于撰写核算依据。
