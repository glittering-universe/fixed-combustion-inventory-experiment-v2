# 实验运行记录分类索引

本目录按 **实验 → 实验组 → 运行编号** 整理当前158条原始运行与人工流程补充索引。为避免破坏结果追溯，本次仅新增分类索引，不移动、删除或重命名已有原始材料。

| 实验 | 组别 | 记录数 | 备注 |
|---|---|---:|---|
| A 方法比较 | 主实验 | 20 | 工业锅炉/火电热力；机器方法各三次，人工方法各一次 |
| B0 基准 | B0 | 8 | 两类源，每类 FULL/GEN/DET/EW |

| **合计** | | **158** | 索引条数，不等同于源对象数 |
