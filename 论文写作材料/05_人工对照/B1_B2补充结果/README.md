# B1、B2人工补充结果

本目录收录本次提交的工业锅炉与火电热力人工补充结果，包含B1的S1—S4和B2，共10组。

- `B1_B2当前版本比较.xlsx`：Full、通用Agent、确定性脚本与专家流程补充的比较表。
- `B1_B2补充结果明细.zip`：各组的源分类、污染物结果、异常清单和运行摘要。
- `B2汇总指标.csv`、`B2逐次指标.csv`：现行评价程序的指标及95%区间。
- `B2逐对象评价`：两类源的逐对象评价结果。
- `原始评价`：B1原始评分及差异明细，用于追溯。

## B1

B0沿用主实验A相应源类的人工结果。人工补充结果与B0的记录范围、过程字段的一致判定尚待核定，因此比较表中的人工保持率标为“待核定”。原始评价保留的0／207,234属于现行整项一致判定输出，不作为正式人工保持率或核算正确率结论。

## B2

每类源包含120个异常对象与30个正常对照。补充结果使用当前统一评价程序计分，分数保持原值。部分记录从已有字段恢复缺失活动水平，或保留可确定的产生量而暂缓最终排放量；这些处置仍按现行定向处置评分规则判定。

本次补充材料中的人工运行各1次；两类Agent各3次，确定性脚本1次。具体结果及区间见比较表和指标文件。
