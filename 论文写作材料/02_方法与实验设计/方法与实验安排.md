# 方法与实验安排

## 数据与核算对象

输入为2022年环境统计基表：企业18,734条、治理设施43,902条、锅炉/燃气轮机候选设备5,922条。两个目标源类分别从候选设备集合组织任务。现行参照分类包含工业锅炉4,046条、火电热力615条和范围外1,261条。

基本处理关系为企业、设备、燃料、排放口与治理设施。核算以污染物排放核算项组织，同一设备可对应多种燃料和多种污染物。NH₃作为SCR/SNCR脱硝过程的氨逃逸核算项，其活动水平和适用条件单独表达。

## 方法组成

| 模块 | 作用 |
|---|---|
| Agent阶段组织 | 组织读取、关联、核算与输出，并汇总处理状态 |
| 污染物排放核算项 | 明确源、燃料、污染物、治理和过程之间的关系 |
| 可执行规则 | 表达适用条件、方法选择、参数来源和核算公式 |
| 核算准入控制 | 根据当前信息决定计算、经验处置、范围处置或待补充 |
| 确定性计算工具 | 执行单位换算、产生量与排放量计算 |
| 过程记录 | 保存输入、规则、参数和中间计算的对应信息 |

采用系数法与燃煤物料衡算，相关参数依据T/CSES 144—2024附录D.1、E.7、A、C及脱硝过程氨逃逸条目。实际采用的参数、映射和规则列在“核算依据”目录。

实验包含经验处置设定，例如治理信息缺失时的零效率、投运率取1和部分多工艺组合的处理方式。这些设定属于实验核算约定，论文中应与指南直接给出的参数分别说明。专业适用性问题见“参照使用与专业问题”。

## 比较方法

- Full完整方法：上述模块共同运行。
- 简单确定性脚本：固定字段映射、燃料映射、参数查表与直接计算。
- 通用工具Agent：使用通用文件、代码与表格工具组织任务。
- 既有专家主导型流程：依据原人工工作簿呈现，具体对照条件见“人工对照”。

## 实验安排

| 实验 | 设计 | 对应结果材料 |
|---|---|---|
| A：端到端编制 | 三种机器方法在两类任务上各运行3次；人工交付按源类分别呈现 | 方法比较、分源类比较、逐次得分 |
| B1：输入形式扰动 | 表头、等价别名、列与工作表顺序、组合扰动；每种扰动各执行1次 | 语义保持率及差异字段 |
| B2：缺失与冲突 | 30个登记对象；26个对象用于定向计分，包括20个正向注入与6个负对照 | 五类宏平均F1、分类表现与处置变化 |
| C：规模与资源 | 25%、50%、75%、100%规模；三种机器方法、两类任务各运行3次 | 单条耗时、总耗时、峰值内存 |
| D：模块贡献 | Full、去除核算项结构、去除规则门控、Agent管理准入、去除完整过程记录；每类各运行1次 | D、N、过程记录覆盖及相对Full变化 |

现有材料共包含136次机器运行和14份人工交付。B1、B2中原人工交付的任务条件与当前扰动输入需要分别说明。

实验A用于综合性能比较。B1、B2、C、D分别提供鲁棒性、规模和模块贡献的补充证据。B与D的单次运行结果用于描述性比较。
