# 结果表说明

各表沿用现有实验评分与汇总数值。D、N、E、保持率、准确率和F1的取值范围为0—1；EICPI_core为0—100。耗时单位为秒，单条耗时按原实验计时口径保留。

| 写作用途 | 文件 |
|---|---|
| 主实验总体表现 | A_方法比较.csv |
| 源类差异 | A_分源类比较.csv |
| 输入形式扰动 | B1_方法比较.csv、B1_各类输入扰动.csv |
| 异常识别与处置 | B2_异常识别比较.csv、B2_分异常类别结果.csv、B2_分源类处置结果.csv |
| 规模与资源表现 | C_规模与耗时.csv |
| 模块贡献 | D_模块消融.csv |
| 重复运行与具体差异 | 全部运行记录.csv |
| 效率计算的基准 | 效率计算基准.csv |

`全部运行记录.csv`中的A/B/C/D表示实验，B0/S1/S2/S3/S4/B2表示输入条件，repetition表示重复编号。空白指标表示该实验或该项当前未给出适用数值。method_boundary相关列为运行过程诊断，供误差分析使用。

人工行的任务条件在“结果用途”列和“人工对照”目录说明。B2保留全部30个登记对象的信息，定向指标采用26个对象。D实验同时呈现过程记录覆盖率，以解释过程记录模块的作用。
